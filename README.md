# 🦟 Mosquito Hunter

**Mosquito Hunter** is a simple 2D casual game built around one funny and satisfying idea: **a mosquito is flying around your room, and your job is to catch it before it escapes.**

The game is designed to be **easy to understand, quick to play, and addictive**. Players click or tap on the mosquito to eliminate it and increase their score. Missing the mosquito isn't a problem, but if it manages to escape, the player loses a life.

The first version focuses on keeping the gameplay simple while making the experience feel polished through **cute 2D visuals, smooth mosquito movement, soft animations, satisfying interactions, and a cozy aesthetic bedroom environment**.

> **Play it live:** [Mosquito Hunter](https://mosquito-hunter-sigma.vercel.app)

## 🎮 Gameplay

- 🦟 Catch the flying mosquito by clicking/tapping it.
- ⭐ Earn **+1 score** for every successful hit.
- ❤️ Start with **3 lives**.
- ⏱️ Catch the mosquito before it escapes.
- 📈 The mosquito gradually becomes faster as the score increases.
- 🏆 Try to beat your highest score.
- 🔄 Restart the game after Game Over.

## 🎨 Design

The game uses a **soft, cozy, pastel nighttime aesthetic** with:

- A cozy bedroom environment
- Cute cartoon mosquito
- Minimal and clean UI
- Rounded buttons
- Soft animations and effects
- Gentle nighttime atmosphere
- Simple and satisfying interactions

## 🚀 Project Goal

The goal of **Mosquito Hunter** is not to create a complicated game, but to turn a very simple idea into a **fun, polished, and replayable 2D experience**.

This project also serves as a small game-development project for experimenting with **2D gameplay mechanics, mouse/touch interaction, animation, scoring systems, UI design, and increasing difficulty**.

## 🔮 Future Improvements

Future versions may introduce new environments, different mosquito behaviors, challenges, and other gameplay elements while keeping the original simple and satisfying gameplay at its core.

## 🛠️ Tech

- Plain HTML / CSS / JavaScript — a single self-contained file, no build step, no dependencies.
- Canvas-free: the scene, furniture, and mosquito are pure HTML/SVG with CSS animations.
- Sounds synthesized live with the Web Audio API.
- Playable on desktop (mouse) and mobile (touch).

## 🚀 Running Locally

Just open `index.html` in any browser, or serve the folder:

```bash
# Python
python -m http.server 8000

# Node
npx serve .
```

## 🚀 Deploying

This project is hosted on [Vercel](https://vercel.com) as a static site. Deploying it yourself is one command:

```bash
vercel --prod
```
